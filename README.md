# Modeling Earth-orbiting Transients, Reflective Objects, and Intrusive Debris (metroid)

<p align="center">
  <img src="assets/metroid.png" alt="Metroid">
</p>

Metroid is an open-source software developed to simulate streaks and trails in astronomical images that are caused by orbital objects such as satellites and space debris.

### Software

### AI-assisted development

In addition to its direct software application, a secondary purpose of this project is to serve as a low-risk platform for the development of an AI-assisted workflow for applications in astronomy.
